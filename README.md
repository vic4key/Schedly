# Schedly

Schedly là một ứng dụng web Python giúp lập lịch và xuất dữ liệu ra file CSV.

## Chức năng chính
- Nhập dữ liệu lập lịch qua giao diện web
- Xử lý và tạo lịch trình tự động
- Xuất kết quả ra file CSV
- Giao diện đơn giản, dễ sử dụng

## Cài đặt nhanh
1. Đảm bảo đã cài Python 3
2. Cài thư viện:
   ```bash
   pip install -r requirements.txt
   ```

## Chạy ứng dụng
```bash
python app.py
```
Sau đó mở trình duyệt và truy cập: http://localhost:5000

## Các file chính
- `app.py`: Khởi động ứng dụng web
- `schedly.py`: Xử lý lập lịch
- `requirements.txt`: Thư viện cần thiết
- `templates/index.html`: Giao diện web

## Kết quả
- Kết quả được xuất ra file CSV trong thư mục dự án
